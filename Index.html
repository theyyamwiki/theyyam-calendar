അഡ്മിൻ ലോഗിൻ / Pending എഡിറ്റുകൾ

ഈ ബോക്സിൽ Kavu ID അല്ലെങ്കിൽ പേര് ടൈപ്പ് ചെയ്ത് തിരയാം. കാവ് തിരഞ്ഞെടുത്താൽ അതിന്റെ Kavu ID ഇവിടെ കാണും. പുതിയ കാവിന് ID സ്വയം ഉണ്ടാകും.
കാവ് തിരഞ്ഞെടുത്താൽ നിലവിലുള്ള നോട്ടീസ് ഇവിടെ കാണും. പുതിയത് തിരഞ്ഞെടുത്താൽ "സേവ് ചെയ്യുക" ക്ലിക്ക് ചെയ്യുമ്പോൾ അപ്‌ലോഡ് ആകും.
